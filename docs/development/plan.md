# 作業計画

## β11の区切り

β11は「ライブラリ拡充のための道具作り」と基本ライブラリの整備を完成範囲とします。実装とローカル検証は完了しました。経緯・合意した仕様・検証結果は[β11の開発記録](beta11.md)に保存しています。

| 分野 | 完成範囲 |
|---|---|
| 型とコピー | 空のstruct、再帰型・循環共有、__copy__への統一、struct・enumのコピー・等値比較・ハッシュの自動生成と手動優先 |
| ライブラリ作者の道具 | 独自の辞書キー、readonlyの返却値・要素・型引数、Int・Boolの値引数、型付きexternへの接続 |
| メタ情報 | 処理系の版・リビジョン・変更状態・公開元のAPI、生成C++へのRuskソース全文と識別情報の記録 |
| 既存例の標準化 | UnionFind・FenwickTree・セグメント木・PriorityQueue、剰余累乗・素数判定・Z-algorithm・LCS・グリッドBFS |
| 基本ライブラリの拡充 | BigInt、IntArray、BitVec・Bits、Deque・Array・Slice、OrderedSet・MultiSet・OrderedDict、順列・選択・整列集合・累積演算 |

通常・最適化なしの回帰検査、公開問題（AOJ 41解答・Library Checker 10解答）、リーク検査を含むASan / UBSan 100ケースが成功しています。追加ライブラリの専用テストは16組です。整形・Clippy・文書ビルドも確認しました。検証対象の正本と実行方法は[テストの実行](verification.md)を参照してください。

## 完成前の文書点検

実装済みの機能を未対応としていたREADME・機能一覧・エラー案内・設計ノートを更新し、自動生成の範囲とスライスの規則を実装へ合わせました。掲載例18組とAPI検査7組、MkDocs strictビルド、文書生成のPythonテスト3件が成功しました。生成サイト67ページのページ内リンク1,776件も確認し、整列コンテナへのリンク切れを修正しました。

実装の区切りとリモートでの完成確認は分けます。コミット・push後のテストCIと文書CIの成功、および公開サイトの反映を最終確認してβ11を閉じます。

## β12の区切り

β12は高度なデータ構造とグラフ・文字列・数論のアルゴリズムを追加し、テストCIと文書CIを通過しました。追加した機能と開発経緯は[β12の開発記録](beta12.md)にまとめています。β13の起点はβ12の完成コミット `fe6ba14` です。

## β13で取り組むこと

Ruskの実行に必要な定義を依存関係から求め、C++への出力を絞ります。対象は関数、構造体・列挙型、extern宣言とその補助コードです。関数値、型付きextern、自動生成するコピーや比較からの参照も扱います。未使用の定義にも型検査を行います。

BigIntの高速乗算、追加のスライス対象、readonlyを含むネイティブ走査の解析精度は継続課題です。

## 正式版0.1.0までの確認

β期間は本番のコンテストに導入しません。生成C++へ元ソース全文を記録する方針は維持し、正式版までに提出先の条件、出典・版との対応、コメントの可逆性、提出サイズと再現性を確認します。これはβ11の完成条件とは分けます。[記録形式](../getting-started/cli.md)と[将来の方針](../future.md)を参照してください。
